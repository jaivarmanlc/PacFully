PACFULLY COST ESTIMATOR - FORMULA REFERENCE
===========================================

Purpose
-------
This file describes the costing formulas currently implemented by the
application. It is a human-readable reference; runtime formulas are managed
separately in Formula Configuration and configurable rates are managed in
Master Configuration. Updating this file alone does not change calculations.


Notation
--------
QTY       = order quantity
CEILING(x)= round x up to the next whole number
L, W      = sheet length and width
Rate      = configured rate for the material or process


1. KAPPA BOARD
--------------
Effective GSM = GSM at 1 mm x Thickness (mm)
Sheet Area = Sheet Length (inch) x Sheet Width (inch) * 0.00064516
KG / Sheet = Sheet Area  x Effective GSM / 1,000
Base Sheets = CEILING(QTY / UPS)
Wastage Sheets = CEILING(Base Sheets x Wastage Percent / 100)
Final Sheets = Base Sheets + Wastage Sheets
Total KG = Final Sheets x KG / Sheet
Per Sheet Cost = KG / Sheet x Rate / KG
Total Cost = Total KG x Rate / KG
Cost / Box = Total Cost / QTY

The Per Sheet Cost trace value is displayed to 2 decimal places. The Kappa
total cost and cost per box use the same underlying KG / Sheet and rate values.
Master Configuration defaults Kappa wastage to 10%; the value is editable
globally or for a specific estimate/component.

Current example:
  Effective GSM = 1,200 x 1.8 = 2,160
  Sheet Area = 39.37 x 27.56 *0.00064516 = 0.7000 
  KG / Sheet = 0.7000 x 2,160 / 1,000 = 1.5120 kg
  Base Sheets = CEILING(1,000 / 2) = 500
  Wastage Sheets = CEILING(500 x 10 / 100) = 50
  Final Sheets = 500 + 50 = 550
  Total KG = 550 x 1.5120 = 831.6000 kg
  Per Sheet Cost = 1.5120 x INR 80 = INR 120.96 / sheet
  Total Cost = 831.6000 x INR 80 = INR 66,528.00
  Cost / Box = INR 66,528.00 / 1,000 = INR 66.528 (displayed as INR 66.53)


2. WRAPPER
----------
Effective GSM = From Material type (Layout)
Base Sheets = CEILING(QTY / UPS)
Wastage Sheets = CEILING(Base Sheets x Wastage Percent / 100)
Final Sheets = Base Sheets + Wastage Sheets + Make-ready Sheets
KG / Sheet = Sheet Length (mm) x Sheet Width (mm) x GSM / 1,000,000,000
Total KG = Final Sheets x KG / Sheet
Total Cost = Total KG x Rate / KG
Cost / Box = Total Cost / QTY

Wrapper GSM comes from the selected material/layout. The formula engine uses
the millimetre dimensions directly for KG / Sheet. Master Configuration
defaults Wrapper wastage to 10%; the value is editable globally or for a
specific estimate/component.



2. INSERTS
----------
For Kappa, FBB, and Duplex board inserts, use the Kappa board weight/sheet
formula with the insert GSM, sheet size, UPS, wastage, and material rate.

For EVA, EPE, and PU, select one pricing method:

Thickness-based:
  Total Cost = Rate per 10 mm x Insert Thickness (mm) / 10
               x Insert Pieces per Box x QTY
  Default rate = INR 750 per insert per 10 mm

Fixed per insert:
  Total Cost = Configured Cost per Insert x Insert Pieces per Box x QTY

Per kg:
  Total Cost = Insert Weight (g) / 1,000 x Rate / KG
               x Insert Pieces per Box x QTY

The fixed-per-insert and per-kg rates must be configured in Master
Configuration; those methods do not silently use a zero rate. The selected
method and required input values are entered for each insert component.



3. PRINTING
-----------
Input Sheets = Wrapper Final Sheets

If Input Sheets <= 1,000:
  Total Cost = First 1,000 Sheets Rate
Otherwise:
  Total Cost = First 1,000 Sheets Rate
               + (Input Sheets - 1,000) x Additional Rate per Sheet

Default rates by sheet size:
  15x20: first INR 1,500; additional INR 0.40 per sheet
  20x28: first INR 3,500; additional INR 0.50 per sheet
  28x40: first INR 6,500; additional INR 0.80 per sheet
Unknown sheet sizes use the 28x40 rate.
This tiered formula applies to Offset printing. Digital printing is
CONFIGURATION REQUIRED until its rates are configured.


3A. DRIP-OFF AND SPOT UV
------------------------
Cost / Sheet = Sheet Length (in) x Sheet Width (in)
              x Rate per 100 sq.in / 100
Total Cost = Cost / Sheet x Wrapper Final Sheets

Drip-Off requires a rate selection of INR 0.90 or INR 0.95 per 100 sq.in.
Spot UV uses its configured rate (default INR 1.00 per 100 sq.in). Both use
the final Wrapper sheet count.



4. LAMINATION
-------------
Cost / Sheet = Sheet Length (in) x Sheet Width (in)
              x Rate per 100 sq.in / 100
Total Cost = Cost / Sheet x Wrapper Final Sheets

Default rate per 100 sq.in:
  Thermal = INR 1.10
  Cold    = INR 0.70
  Dry     = INR 0.80
Unknown lamination types use the Thermal rate.


5. GLUE
-------
For each glue component:
  Area (m^2) = Area (sq.in) x 0.00064516
  Glue KG per box = Area (m^2) x GSM / 1,000
  Component Cost = Glue KG per box x Rate / KG x QTY

Total Glue Cost = Sum of Component Costs for all glue components

6. PUNCHING
-----------
Production Hours = QTY / Machine Speed (sheets per hour)
For Wrapper material, punching input quantity = Wrapper Final Sheets.
For other punching materials, punching input quantity = QTY.
Total Cost = (Production Hours + Setup Hours)
             x Machine Rate per Hour

Default speed and setup time:
  Kappa:       400 sheets/hour, 0.5 setup hours
  Wrapper:     600 sheets/hour, 0.5 setup hours
  FBB:         600 sheets/hour, 0.5 setup hours
  Duplex:      600 sheets/hour, 0.5 setup hours
  Foam/EVA/EPE:500 sheets/hour, 0.5 setup hours
Unknown materials use the Kappa settings.

Machine Rate per Hour = 400 rs

7. EMBELLISHMENTS
-----------------
Foiling:
  Raw Cost / Box = Component Area (sq.in)
                   x Foiling Rate per 100 sq.in / 100
  Total Cost = Maximum(Raw Cost / Box, Minimum Cost / Box) x QTY

Spot UV and Drip-Off use the per-sheet formulas in section 3A.

Embossing / Debossing:
  Total Cost = Configured Direct Cost per Box x QTY
  Default direct cost = INR 1 per box for each process

Die costs are calculated separately in One Time Tooling Cost.

The standalone legacy embellishment calculator (without component-process
inputs) uses:
  Raw Cost = Area (sq.in) x Rate per sq.in + Setup Cost
  Total Cost = Maximum(Raw Cost, Minimum Tool Cost)


8. ACCESSORIES
--------------
Accessory Cost = Quantity per Box x Unit Cost x QTY
Total Accessories Cost = Sum of Accessory Costs


9. CONVERSION
-------------
Choose a conversion type and base material. The module-only calculator and
component-process calculator use the same formulas. Semi Automatic is the
default method for Kappa.
The old generic conversion formula is retained for saved-configuration
compatibility but is not used by active conversion calculations.

Semi Automatic:
For Kappa, the default boxes converted per hour is 400 and is configurable.

Machine Hours = (QTY / Boxes Converted per Hour) x 2

Labour Rate / Hour = Monthly Salary per Worker / Working Days / Hours per Day
Total Labour Cost = Number of Workers x Labour Rate / Hour x Machine Hours
Cost / Box = Total Labour Cost / QTY

For FBB, Duplex, and Kraft with Semi Automatic selected:
  Total Cost = Side Pasting Rate / Box x QTY


Automatic:
For Kappa, defaults are 600 boxes/hour, INR 875/hour machine rate,
INR 645/hour setup rate, and 4 setup hours. These values are configurable.
Machine Hours = (QTY / Boxes Converted per Hour) x 2
Total Cost = (Machine Hours x Machine Rate / Hour)
             + (Setup Hours x 2 x Setup Rate / Hour)
Cost / Box = Total Cost / QTY
Automatic conversion is supported for Kappa only.




Contract: (If conversion is Contract)

Total Cost = Contract Rate per Box x QTY
Cost / Box = Total Cost / QTY


9A. ONE-TIME TOOLING COST
-------------------------
Punching Die cost is a one-time amount selected from the nearest configured
sheet size:
  15x20 = INR 1,500
  20x28 = INR 3,000
  25x36 = INR 4,000
  28x40 = INR 4,000

Emboss/Deboss Die Total Cost = Area (sq.cm) x Configured Rate per sq.cm
Foil Stamp Die Total Cost = Area (sq.cm) x Configured Rate per sq.cm
Default rate for each = INR 5 per sq.cm



10. EB
------
EB remains CONFIGURATION REQUIRED. Its inputs do not currently produce a
costing result.


11. ESTIMATE TOTALS, WEIGHTAGE, AND MARGIN
------------------------------------------
Total Manufacturing Cost = Sum of all module Total Costs
Module Cost / Box = Module Total Cost / QTY
Overall Cost / Box = Total Manufacturing Cost / QTY
Module Weightage (%) = Module Total Cost / Total Manufacturing Cost x 100
                       (0 when Total Manufacturing Cost is 0)

Selling Price / Box = Overall Cost / Box / (1 - Margin Percent / 100)
Order Value = Selling Price / Box x QTY


12. QUOTATION / PROFORMA TOTALS
-------------------------------
Subtotal = Selling Price / Box x QTY
GST Amount = Subtotal x GST Percent / 100
Grand Total = Subtotal + GST Amount


RATE INPUT NOTE
---------------
Kappa and Wrapper resolve the Estimate Override first, then the configured
Master Rate, then the existing backend fallback rate. Lamination selects its
Master Rate from the lamination type table; an Estimate Override replaces that
rate. Printing uses the selected sheet-size rate table as its default
first-tier rate; an Estimate Override replaces that first-tier rate, while the
table's additional-sheet rate remains unchanged. Glue components use their own
configured rates, and Punching uses the configured machine rate per hour.
Board inserts use the selected material rate; foam inserts use the selected
pricing method and its corresponding Master Configuration rate. Drip-Off uses
the explicitly selected rate from the component input dropdown.


ROUNDING AND DISPLAY
--------------------
The costing engine rounds line totals, cost per box, overall totals, selling
price, and order value to 4 decimal places in its response. Module weightage is
also rounded to 4 decimal places. The UI commonly formats currency to 2 decimal
places, so a response value such as 66.528 is displayed as 66.53.
